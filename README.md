# 🏆 Score-Flow

Sistema integral para la gestión de competidores y generación automatizada de pirámides de competencia (brackets). Este proyecto utiliza una arquitectura moderna desacoplada, garantizando que la lógica de torneos sea precisa y escalable.

## 🏗️ Arquitectura del Proyecto

Este proyecto está organizado como un **monorepo**, dividiendo la lógica de negocio del cliente visual:

* **/backend**: API REST construida con **FastAPI** y **Python 3.13**. Implementa **DDD (Domain-Driven Design)** y se desarrolla bajo la metodología **TDD (Test-Driven Development)**.
* **/frontend**: Interfaz de usuario interactiva construida con **Vue 3**, **TypeScript** y **Vite**.
